# Calculator

A responsive calculator built as part of my **CodeAlpha Web Development Internship** (Task 2).

## Features
- Addition, subtraction, multiplication and division
- Clean interface with buttons and a display screen
- Handles user input, clear button and real-time result display
- Responsive design

## Technologies Used
- HTML5
- CSS3
- JavaScript

## How to Run Locally
1. Clone the repository:
   ```
   git clone https://github.com/Komal54175/CodeAlpha_Calculator.git
   ```
2. Open `index.html` in your browser.
